# ObsyBrain — el brain de arranque

Este brain viene con el conocimiento base de LaKademIA: cómo trabajamos con IA, cómo
se organizan los agentes, qué convenciones seguimos y qué problemas ya resolvimos.
Empezá por [[wiki/como-trabajamos|cómo trabajamos]] y después recorré los temas.

## Qué hay adentro

- **wiki/como-trabajamos** — la filosofía de trabajo: vos dirigís, la IA ejecuta.
- **wiki/agentes** — qué es un agente, cómo se conecta a este brain y qué puede hacer.
- **wiki/prompts** — cómo se escribe una instrucción que produce buen trabajo.
- **wiki/estructura-de-conocimiento** — cómo se organiza un brain para que la búsqueda funcione.
- **wiki/memoria-y-contexto** — qué guardar, qué olvidar y cuándo.
- **wiki/playbooks** — recetas paso a paso para las tareas más comunes.
- **raw/notas** — notas de trabajo y fragmentos citables.
- **decisions** — las decisiones ya tomadas y por qué.
- **log** — el registro de cambios de este pack.

## Para qué sirve

Cuando le preguntes algo a tu agente ("¿cómo armo un prompt para X?", "¿qué convención
seguimos para Y?"), la respuesta viene de aquí. El valor del brain crece con lo que
vos le agregues: este es el punto de partida, no el final.
