## ObsyBrain v0.7.3

La Guía se lee por secciones.

- **Sección por sección, sin scroll eterno.** La Guía se lee con una lista de secciones a la izquierda y una a la vez a la derecha; los enlaces «Siguiente →» cambian de sección y un enlace profundo (`/guia#seccion-07-agente`) abre la sección exacta. En pantallas angostas, la lista se pliega en una tira de secciones arriba.
- **El taller PRO.** `deploy/taller-pro.html`: el deck interactivo del taller de 90 minutos — instalar, conectar el agente, el ciclo diario y soberanía, con los comandos listos para copiar.

---

**Instalación:**

```sh
curl -fsSLO https://github.com/JJRProDigital/obsybrain/releases/download/v0.7.3/obsybrain.sh
sha256sum obsybrain.sh   # debe coincidir con el hash de abajo
sh obsybrain.sh install --local
```
