Conectá tu agente

Tu ObsyBrain es un servidor MCP: cualquier agente de IA que hable MCP puede leerlo, buscar en él y — si le das permiso — escribir en su diario y proponer páginas para el wiki.

Antes de empezar

Necesitás dos cosas:

1. Tu instalación corriendo (la web responde en http://localhost:8090, o en tu dominio si instalaste en un VPS).

2. Un agente de IA que soporte MCP: Claude Code, Codex, OpenCode o Cursor. Otros agentes pueden usar el puente local (obsybrain bridge).

Si tu instalación está en un servidor con dominio, reemplazá http://localhost:8090 por https://tudominio.com en todos los comandos. La página Conecta tu agente dentro de tu ObsyBrain genera estos mismos bloques con tu dirección real.

Camino 1 — Conexión estándar (recomendado)

Sin tokens ni archivos de configuración: el agente abre tu navegador una vez y vos aprobás allí.

Claude Code

# en una terminal, en tu carpeta de trabajo:
claude mcp add --transport http obsybrain http://localhost:8090/mcp --scope user
claude mcp login obsybrain

El navegador abre la página de tu ObsyBrain para aprobar el acceso. Con eso, cada sesión de Claude Code arranca con tu brain en el contexto.

Codex

codex mcp add obsybrain --url http://localhost:8090/mcp
codex mcp login obsybrain

OpenCode

# en opencode.json:
{ "mcp": { "obsybrain": { "type": "remote", "url": "http://localhost:8090/mcp" } } }

Cursor

# en .cursor/mcp.json:
{ "mcpServers": { "obsybrain": { "url": "http://localhost:8090/mcp" } } }

Camino 2 — Con un token (para agentes sin navegador)

Si tu agente corre en un servidor, un contenedor o sin navegador, usás un token de acceso:

  1. En la web de tu ObsyBrain: Perfil › Claves › Crear un token, con permiso de lectura y escritura.
  2. Guardalo en un archivo que solo vos puedas leer: ~/.config/obsybrain/token (permiso 600). Nunca en la línea de comandos.
  3. Seguí el bloque de configuración que la página Conecta tu agente genera para tu cliente — cada agente usa su propia variable (OBSY_BRAIN_TOKEN_CLAUDE_CODE, OBSY_BRAIN_TOKEN_CODEX, etc.) para que dos agentes nunca se pisen.

El puente, para agentes que solo arrancan programas MCP locales

obsybrain bridge --url http://localhost:8090/mcp

Como servidor MCP local: {"command": "obsybrain", "args": ["bridge", "--url", ""]}. El token viene de --token-file, o de OBSY_BRAIN_TOKEN, o de ~/.config/obsybrain/token.

La prueba

Preguntale a tu agente:

¿Qué sabés sobre cómo armar un prompt?

Si responde con el material de tu brain (el starter pack trae la anatomía del prompt) — y no con una respuesta genérica del modelo —, la conexión funciona. En la web, la página Conecta tu agente te muestra «Conectado» con la hora exacta.

¿Qué puede hacer el agente una vez conectado?

Con lectura: buscar en todos tus brains, leer páginas del wiki, consultar el diario.

Con lectura y escritura: guardar entradas del diario mientras trabaja, y proponer cambios al wiki (las propuestas esperan la aprobación de un curador — nada entra sin pasar por tus ojos).

¿Problemas?

· «Conectado» no aparece: revisá que la web responda en el navegador con la misma dirección que pusiste en el comando.

· El agente responde genérico: el brain probablemente está vacío — importá el starter pack (Paso 3 de la Guía de onboarding).

· Error 403 con una clave: la clave no tiene permiso de escritura, o la importación la hace solo una persona en la web.

· Más ayuda: el manual completo vive dentro de tu ObsyBrain, sección Guía (ícono libro en la barra lateral).
